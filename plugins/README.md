# Runtime Plugins

Purpose: future Sandbox application/runtime provider extensions distributed as product components.

Owner: SDKWork Sandbox provider maintainers.

Allowed: installable runtime plugin source, component contracts, conformance fixtures, and tests. Forbidden: repository agent plugins, generated SDK output, live secrets, and runtime state.

Related specs: `../../sdkwork-specs/COMPONENT_SPEC.md`, `../../sdkwork-specs/MODULE_SPEC.md`, `../../sdkwork-specs/SECURITY_SPEC.md`.

Verification: inactive in Phase 0; runtime plugins require component and conformance checks.
