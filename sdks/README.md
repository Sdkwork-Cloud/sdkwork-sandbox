# SDK Families

Purpose: SDKWork Sandbox SDK family workspaces and generator-owned outputs after an API authority is approved.

Owner: SDKWork Sandbox SDK maintainers.

Allowed: SDK manifests, composed facades, materialized authority inputs, generated language workspaces, and component specs. Forbidden: the sole authored API source, hand-edited generated transports, raw HTTP wrappers, and secrets.

Related specs: `../../sdkwork-specs/SDK_SPEC.md`, `../../sdkwork-specs/SDK_WORKSPACE_GENERATION_SPEC.md`.

Verification: inactive in Phase 0; activate only after `apis/` authority and generation ownership are approved.
