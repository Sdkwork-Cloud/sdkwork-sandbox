# Examples

Purpose: future runnable, security-safe integration examples for Sandbox consumers and provider authors.

Owner: SDKWork Sandbox developer experience maintainers.

Allowed: bounded sample configurations, consumer examples, and provider integration fixtures. Forbidden: production credentials, copied generated SDKs, unsupported API examples, and private endpoints.

Related specs: `../../sdkwork-specs/DOCUMENTATION_SPEC.md`, `../../sdkwork-specs/SECURITY_SPEC.md`.

Verification: inactive in Phase 0; examples must compile or run in CI when introduced.
