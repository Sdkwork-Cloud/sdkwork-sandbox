# Scripts

Purpose: future thin command entrypoints that delegate to native tools or implementations under `tools/`.

Owner: SDKWork Sandbox engineering maintainers.

Allowed: short build, verification, generation, migration, packaging, and release wrappers. Forbidden: reusable business logic, hidden dependency manifests, generated SDKs, and credentials.

Related specs: `../../sdkwork-specs/CODE_STYLE_SPEC.md`, `../../sdkwork-specs/PNPM_SCRIPT_SPEC.md` when pnpm is introduced.

Verification: inactive in Phase 0.
