# SDKWork Repository Workspace

Purpose: source-controlled development metadata for `sdkwork-sandbox`.

Owner: SDKWork Runtime Platform maintainers.

Authoritative directories are `skills/` for reusable repository workflows, `plugins/` for agent-tool plugins, and `manifests/` when repository metadata is later required. `local/`, `tmp/`, `cache/`, `secrets/`, and `manual-backups/` are ignored local state and must never contain committed runtime or credential data.

Global rules: `../../sdkwork-specs/SDKWORK_WORKSPACE_SPEC.md` and `../../sdkwork-specs/SECURITY_SPEC.md`.
