# Repository Contracts

Purpose: repository-wide machine contracts spanning more than one Sandbox component.

Owner: SDKWork Runtime Platform maintainers.

No cross-component machine contract is active in Phase 0. Component contracts live beside each crate at `crates/<crate>/specs/component.spec.json`. Future topology, deployment, or composition manifests may be added here only when they are the machine source of truth.

Global standards remain at `../../sdkwork-specs/`; do not copy their bodies into this directory.
